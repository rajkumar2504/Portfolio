# Rajkumar R. — Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It has no framework, build step, or package dependencies.

## Run locally

Open `index.html` in a browser, or serve the repository folder with any static file server.

## Files

- `index.html` — page structure and content
- `style.css` — layout, styling, responsive breakpoints, and reduced motion support
- `script.js` — mobile navigation, copyright year, and copy email interaction
- `assets/images/profile.jpg` — provided portrait
- `assets/resume/Rajkumar_Resume.pdf` — provided resume

## Deploy to GitHub Pages

The workflow at `.github/workflows/deploy.yml` publishes the static site whenever changes are pushed to `main`, or when manually dispatched.

1. Push the repository to GitHub and open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push to `main` and follow the deployment in the **Actions** tab.

The requested site URL is <https://rajkumar2504.github.io/developer-portfolio/>. The GitHub repository must be named `developer-portfolio` for that exact URL. This checkout's current remote is `rajkumar2504/Portfolio`.
